# Plan de implementación — hallazgos de QA 2026-08-20

Rama: `experiment/autonomous-explorer`. Sin merge a master; el PR va después.
Cada fase deja la suite verde (`17/17`) antes de pasar a la siguiente.

Criterio de diseño: **ningún arreglo introduce una pieza nueva si una existente
ya resuelve el caso**. Tres de los bugs (B1, B4, B9) son la misma falla: una
protección que existe en un lugar y no se propagó al de al lado.

---

## Fase 1 — Seguridad (B1, B2, B7)

**1.1 · Un solo validador de nombre de archivo** — `ui/server.py`

`_archivo` valida bien; `_guardar_snapshot` no. Extraer el cuerpo de `_archivo` a
`_ruta_segura(nombre, carpeta, sufijo="")` y hacer que las dos lo usen. No es una
abstracción nueva: es mover la que ya existe a donde también hacía falta.

- Verificación: `POST /api/snapshot` con `board: "C:/tmp/x"` → 400, nada en disco.

**1.2 · El grafo deja de viajar como código** — `_generar_script_python`

Hoy el grafo se interpola en el fuente del script (`GRAFO = {json}`) y el board
dentro de un literal. Cambiar a un bloque JSON leído en runtime:

```python
GRAFO = json.loads(r"""<json>""")
```

Cierra B2 (inyección por el board) y B7 (`true`/`null`) con el mismo cambio,
y el script queda más corto. Escapar `"""` en el JSON no hace falta: `json.dumps`
ya escapa las comillas dobles.

- Verificación: script generado desde un board con `" ; import os` y desde un
  grafo con booleanos → `compile()` OK y `json.loads` devuelve el grafo original.

## Fase 2 — Features muertas (B3)

**2.1 · `"respuesta"` → `"texto"`** — `ui/server.py:205, 468`

Dos líneas. Es el bug entero.

**2.2 · Que la próxima no tarde tanto en verse**

El `except Exception: return goal_limpio` de `_optimizar_goal` y el
`except: return dry_run` de `_generar_grafo` son los que taparon B3 durante toda
su vida. No se sacan (el fallback es correcto: sin CLI hay que degradar), pero
pasan a **decir que degradaron**: la respuesta lleva `"degradado": true` y el
motivo, y la UI lo muestra en ámbar en vez de "con éxito".

**2.3 · Borrar el fallback duplicado (D2)** — el mismo bloque de `partes = [...]`
está escrito tres veces. Queda una función de cuatro líneas.

- Verificación: `test_chat.py` extendido con un caso que prueba que
  `_optimizar_goal` cambia el goal cuando el backend responde, y que marca
  `degradado` cuando no.

## Fase 3 — Dispatcher (B4, B9, B10)

**3.1 · El heartbeat abre la base del board** — `dispatcher/loop.py`

`ejecutar_una(conn, task_id, *, board=None, ...)`; el hilo de latido usa
`k.connect(board=board) if board else k.connect()`, igual que `tick`. `tick` ya
tiene el board y lo pasa. Además, se **mira el retorno**: si `heartbeat_claim`
devuelve `False` perdimos el claim, y eso se imprime en vez de seguir latiendo
contra el vacío.

- Verificación: test nuevo que corre un nodo en un board no-default con un
  backend falso lento y comprueba que `claim_expires` avanzó.

**3.2 · `jsonschema` se importa arriba** — `dispatcher/backends.py`

Sacar el `import jsonschema` de adentro de `_validar`. Una dependencia dura que
falta tiene que romper al importar, ruidoso y una vez, no disfrazarse de contrato
incumplido y reintentarse dos veces por nodo. El docstring del módulo ya la
declara dura.

**3.3 · `_queda_trabajo` cuenta `ready`** — una palabra en la tupla.

## Fase 4 — Superficie HTTP (B5, B6, B8, B11)

**4.1 · Parseo del pedido adentro del `try`** — `do_POST`

Mover `Content-Length` y `json.loads` dentro del bloque, con `except ValueError`
→ 400. Tope de cuerpo de 8 MB: esto acepta grafos, no subidas.

**4.2 · `parse_qs` de la stdlib** en vez del `split("=")` a mano. Una línea, y
además arregla el token pasado por URL con caracteres escapados.

**4.3 · `activos` suma** en vez de `or`.

**4.4 · `_traza` y `_generar_reporte_corrida` envuelven `connect`** como ya hace
`_estado`: `{"error": ...}` en vez de 200 sobre una base recién inventada.

- Verificación: `test_ui_expansion.py` extendido — cuerpo malformado → 400 con
  JSON, `?nombre=mi%20flujo` abre el grafo `mi flujo`.

## Fase 5 — API multiusuario (B12, B13)

**5.1 · Rate limit en `/auth/login` y `/auth/registro`**

Contador en memoria por IP en el guard que ya existe (`GuardiaAuth`), ventana
deslizante simple. Sin `@nestjs/throttler`: es una dependencia nueva para doce
líneas, y esta API todavía no está conectada al Studio.

**5.2 · Aviso de arranque por `ORQUESTER_TOKEN`** junto al de `DATABASE_URL`.
Sin la variable, todas las llamadas al motor dan 404 y el mensaje no lo explica.
